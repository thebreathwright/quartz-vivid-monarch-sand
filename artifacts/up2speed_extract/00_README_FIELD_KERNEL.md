# Respiratory Adaptation Canon — Field Kernel

## 0. Purpose

This directory is the first **Canonical Reconstruction System** seed for `_PKG_MKR_GLOBAL_`.

It is not a folder cleanup, a book outline, or another essay. It is a machine-readable and human-readable layer above the raw archive. Its job is to preserve the source archive while extracting a coherent field architecture that can support rewriting, sequencing, retrieval, AI reasoning, publication planning, ontology enforcement, contradiction detection, curriculum generation, and future archive expansion.

The branch-session state is clear: the archive should be treated as an **uncompressed proto-field**, not as a document pile. The field kernel is:

> Living systems adapt to load; respiration is the most neglected adaptation domain; the archive is a proto-field around respiratory adaptation, water/heat economics, and causal-language repair.

## 1. Core Premise

**Respiratory, craniofacial, vascular, glandular, sensory, linguistic, and symbolic systems are best interpreted through adaptive response to load, flow, pressure, heat, chemistry, language, water, and embodied observation.**

This premise does not assert that every downstream claim is established. It creates a causal grammar for separating and testing claims. The core discipline is:

```text
Law → Mechanism → Measurement → Intervention → Outcome → System consequence → Language repair → Symbolic convergence
```

The symbolic layer is deliberately late-bound. Grail/DJED/WAS/ANKH/Jalandhara/Tree/Second-Death motifs are preserved, but they do not lead the scientific sequence.

## 4. The Conditioning Tree Thesis

The central physiological object is the **Conditioning Tree**: the nose-to-bronchial-to-alveolar support stack considered as a trainable heat-water-energy recovery organ.

The corrected functional ordering is:

```text
humidify / recover water
→ distribute / recover heat
→ maintain patency
→ absorb / sense / clear / respond
→ filter
```

This reverses the common shallow ordering "filter → warm → humidify." The canon treats **water economy** and **heat-water recovery** as the first-order economic burden, with filtration treated as a downstream simplification of a more complex absorptive, sensing, ciliated, secretory interface.

## 7. Claim-Strength Ladder

Every claim must be assigned one or more levels:

| Level | Meaning |
|---|---|
| `L0_source_text` | Raw statement exists in archive; no independent assertion yet. |
| `L1_observed` | Personal, branch-session, or field observation; real source statement but not necessarily externally measured. |
| `L2_modeled` | Calculated, scenario-modeled, or systems-modeled claim; depends on assumptions. |
| `L3_literature_supported` | Mechanism or parameter has external literature support, even if full archive synthesis is novel. |
| `L4_measured_internal` | Measured by user/archive data or instrumentation; requires source data link. |
| `L5_replicated_internal` | Repeated across trainees/cases inside the corpus; requires de-identified records. |
| `L6_pilot_tested` | Bounded pilot protocol with predefined measures. |
| `L7_peer_review_ready` | Publication-ready claim after citations, methods, assumptions, and safety are formalized. |
| `L8_established` | Broadly accepted in external literature. |
| `S_symbolic` | Symbolic/comparative/anatomical mapping; not historical-intent proof. |
| `X_speculative` | Exploratory hypothesis or extrapolation; useful for research design, not asserted fact. |
| `R_rhetorical` | Forceful language, indictment, polemic, or public-facing emphasis; not evidence layer. |


No claim should be promoted upward without a validation path. Symbolic and rhetorical claims can remain in the archive, but they must be tagged so they do not contaminate empirical claims.

## 9. Rewrite Fates

Each source document should receive one or more rewrite fates:

```yaml
rewrite_fates:
  canon_seed: foundational and should be rewritten first
  evidence_support: supports another canonical paper
  protocol_source: extract training instructions and safety rules
  symbolic_source: preserve as humanities/symbolic layer
  polemic_to_policy: rewrite as omission audit or policy critique
  merge_candidate: redundant with stronger documents
  raw_archive_only: preserve but do not foreground
  deprecated_or_unsafe: retain for provenance but block as active instruction
```

## 11. Safety and Translation Firewall

Protocol-like material must pass through `10_protocol_safety_firewall.yaml` before public rendering. The firewall distinguishes:

- historical/symbolic discussion,
- hypothesis-only research framing,
- supervised pilot-only protocol framing,
- non-combustion analogues,
- and blocked public instruction.

This is structural hygiene, not censorship. It allows the archive to preserve raw source material while preventing unsafe extrapolation into public instructions.
